# Water Scarcity Level Prediction

A machine learning project for predicting water scarcity levels using environmental and water-related data.

# Project Overview

Water scarcity is an important environmental challenge that can affect agriculture, communities, and natural resources.

This project uses machine learning classification algorithms to predict the level of water scarcity based on relevant environmental and water-related features.

The model classifies water scarcity into three levels:

- Low
- Moderate
- High

# Objective

The main objective of this project is to develop and evaluate machine learning classification models that can predict water scarcity levels from available data.

The project also compares the performance of multiple classification algorithms using training and testing accuracy.

# Technologies Used

- Python

- NumPy

# Machine Learning Models

The following classification algorithms are used in this project:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. AdaBoost Classifier
5. Gradient Boosting Classifier
6. K-Neighbors Classifier (KNN)
7. Gaussian Naive Bayes (Gaussian NB)
